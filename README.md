# SWE Eval Integrity

Research on evaluating coding agents through software engineering tasks.
The methodology covers task design, grading controls, measurement and evidence.

- [Evaluation lifecycle](methodology/evaluation-lifecycle.md)
- [Measurement and evidence](methodology/measurement-and-evidence.md)
- [Research references](references/sources.bib)

The first study will test whether a report's score and counts can be
reconstructed from individual case outcomes. This foundation records the method
and prediction. The runnable study follows in the next stage.
