# Working in this repository

This is an independent public evaluation engineering project. Keep claims tied
to public, reproducible evidence and maintain the disclosure boundary below.

## Changes

- Read the relevant study and methodology before editing. Keep changes narrow.
- State a prediction before an experiment. Retain contradictory results and
  distinguish hypotheses, saved-result analysis and new execution.
- Accept correct alternatives and test plausible incorrect outcomes when
  changing an evaluator. Do not weaken a check to match a generated report.
- Keep the core runtime dependency-free on Python 3.11 or later. Record any new
  dependency and its license before introducing it.
- Report the exact commands run and their outcomes. State checks not run.
- Use plain English and normal hyphens. Do not invent measurements, affiliations,
  acceptance claims, source metadata, release dates or persistent identifiers.

## Public disclosure boundary

Admit only independently authored or specifically cleared files. Do not copy
client tasks, internal criteria, hidden cases, reference solutions, platform
exports, transcripts, identities, actual client scores, contractual documents,
private paths or provider secrets. Anonymization alone does not establish rights.

Before publication, enumerate an explicit allowlist of paths and review the
exact staged files and all included Git history. Apply the same review to
generated output, distribution archives, CI logs and attachments. Scan for
secrets and private paths, then manually check meaning, provenance and task
fingerprints. Do not import private history into this repository.

For questions about Codex, ChatGPT, OpenAI plugins or the OpenAI API, follow the
official OpenAI documentation workflow and use the `openaiDeveloperDocs` MCP
server when available. Verify current behavior against the relevant official
source. Keep project instructions here and in linked repository documents.
